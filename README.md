# DND-Manager-App

This app started out as a way to replace the Samsung OneUI Do Not Disturb manager. After moving away to a OnePlus phone and now an Oppo phone, I missed the ability to click on Do Not Disturb and have the ability to select a specific period of time for it to be on, rather than having a plain on/off toggle.

I set out to recreate that, and I have surpassed that Samsung feature in some ways.
DND Manager also has the ability to
- Set any specific time using the Android wheel time picker
- Change what is specifically allowed in, be it Priority contacts/apps, or absolutely no one
- If you exit the app you are using (with a two minute leeway), in case you only exited the app to quickly search something/perform an action in a different app, only to then return

More features will continue to be added as this app is updated
